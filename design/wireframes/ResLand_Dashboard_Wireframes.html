ResLand - Streamlit dashboard wireframes (v0.9)

Mid-fidelity wireframes for the four dashboard screens and their empty, loading, validation-error, run-error and completion states. Configuration values are taken from the paper-default preset; every result value is a placeholder (##) or an illustrative curve shape. One paper-reported row is shown only to demonstrate provenance labelling. Edit this HTML/CSS directly, or import it into Figma with an HTML-to-design plugin.
